## Project Overview
This repository contains the FSAD S52 workbook experiments implemented as part of the academic curriculum.

- Creating repositories
- Basic Git commands (init, add, commit, push)
- Version tracking using GitHub

---

### 🔹 SKILL – 2: Hibernate CRUD Operations
- Create operation
- Read operation
- Update operation
- Delete operation
- Database connectivity using Hibernate ORM

---

### 🔹 SKILL – 3: Working with HQL
- HQL Select Queries
- Sorting of records

### 🔹 SKILL – 4: Spring Dependency Injection

## How to Run the Project
1. Clone the repository from GitHub.
2. Import the project into Eclipse or IntelliJ IDEA.
3. Configure the database in `hibernate.cfg.xml`.
4. Run the main Java classes to execute the experiments.
